# Market Echo

**把相似历史走势、后续幅度和具体换算价位放在一起看。**

从 Wayne 的 Fieldnote 抽离的历史案例研究工具。它帮助你回答“过去有哪些类似走势、后来怎样”，不承诺未来价格，不生成交易指令。

## 启动

安装 Node.js 22+。下载 ZIP 并解压，或用 Git 获取项目：

```sh
git clone https://github.com/pruettlazaro143-a11y/market-echo.git
cd market-echo
```

在项目目录运行：

```sh
npm start
```

打开 http://127.0.0.1:4173 。无需 npm install、账号、数据库。右上角支持中英文切换。首次运行自动加载合成演示，不能当作真实市场数据。

`npm test` 运行测试；`npm run build` 生成 `dist/`。纯静态托管可做本地检索，AI 转发需要 Node 本机服务。不要双击 HTML 文件。

## 基准价和 24 小时终点怎么看

- **基准价**：观察窗口最后一根已收盘 K 线的收盘价。显示真实数据截止时间，不伪装成实时价格。
- **期限终点**：从数据截止时刻往后数，例如 24 小时。股票按交易日处理，未核验日历时不编造具体日期。
- **历史幅度换算价**：当前基准 ×（1 + 某个历史案例的后续涨跌幅）。

例如基准 100、某案例后续 +2%，换算价就是 102。它说明“同等幅度对应什么价位”，不是“未来一定到哪里”。图上标出基准、期限、终点圆点及价格/幅度；案例表同时展示历史原价和当前换算价。

中位数与 P10—P90 只是已选案例的描述性统计，不是预测目标或置信区间。真实未来价格没有数据时会明确留空。

## 分类与范围

| 大类 | 子类 | 首版范围 |
|---|---|---|
| Crypto | BTC / ETH | 形态、结构、波动与可用量能 |
| Crypto | 其他币种 | 仅形态和结构；显示历史幅度，不给换算目标点位 |
| 美股 | 自填股票代码 | 用户导入的数据，同一标的内检索 |
| A 股 | 自填股票代码 | v0.2 先支持日线，不声称已核验节假日 |
| 黄金与金属 | 黄金、白银、其他 | 自带 CSV，区分现货/参考价与期货 |

每类都需要自己的 CSV，不会自动下载行情。价格单位自行填写并与文件一致，例如 USDT、CNY、USD/oz。BTC/ETH 同样没有新闻或基本面验证，不能因为支持量价比较就认为可以预测。

CSV 必需列：timestamp,open,high,low,close；volume,end 可选。时间须为 Unix 秒/毫秒或带时区 ISO 格式。最多 5 MB / 20,000 根，固定比较最近 96 根已收盘 K 线。支持 5m/15m/1h/4h/1d，A 股先限 1d。日线可明确提供真实收盘 end；未提供时按周期推算。请自行统一复权、换月和交易时段。

`examples/synthetic-btc-1h.csv` 为合成 BTC 现货 1h 演示，导入时保留“合成 / 测试数据”标记。

## AI 怎么用

检索完成后，选 DeepSeek、OpenAI 或 Claude，填该供应商真实支持的模型 ID 和自己的 API Key。先展开“将发送的内容”，确认后点击解释。其他兼容 API 需按 [AI.md](docs/AI.md) 在本机配置地址。

选择“为什么匹配”“后续分歧”或“案例对照”三个固定主题。程序先展示前几个案例的统计与对照入口，AI 再作简短解释；不提供自由聊天。数值由程序计算，AI 无权修改图上的点位。输出检查会拒绝新数字与部分操作性措辞，但不保证理解永不出错；用户仍需核对证据。

CSV 检索不上传。AI 经本机服务只发送预览摘要，不发送完整行情文件。密钥仅在页面/请求内存中使用，不写入本项目磁盘、日志或浏览器存储；切换供应商会清除密钥。供应商按其政策处理数据并收取 API 费用。没有自动重试、偷偷切换供应商或用平台密钥兜底。

## 产品边界

相似不等于重演，历史频率不是未来胜率。此工具没有接入新闻、财报、流动性判断或实盘执行；不构成投资建议或收益保证。请勿盲目依赖，也不要把免责声明当成正确性保证。
